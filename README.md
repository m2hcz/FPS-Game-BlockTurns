# FPS Game BlockTurns

Use it team.

## Setup

1. Clone the repository.
2. Open the project folder in Cursor or VS Code.
3. Install the recommended extensions when prompted.
4. Start Rojo:

```powershell
.\scripts\serve.ps1
```

5. Open the Roblox place in Studio.
6. Connect the Rojo plugin to:

```text
localhost:34872
```

## Workflow

- Edit code in `src/`.
- Do not edit Rojo-managed scripts directly in Roblox Studio.
- Commit changes through Git.
- Pull before starting new work.

## Commands

```powershell
.\scripts\serve.ps1
.\scripts\build.ps1
.\scripts\sourcemap.ps1
```
